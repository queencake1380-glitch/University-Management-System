# سامانهٔ مدیریت امور آموزشی دانشگاه

**درس:** مهندسی نرم‌افزار | **نوع:** پروژهٔ دانشگاهی

## معرفی
این پروژه یک سامانهٔ پیشنهادی برای مدیریت اطلاعات دانشجویان، استادان، درس‌ها، انتخاب واحد و نمرات است. هدف، منظم‌کردن امور آموزشی و فراهم‌کردن دسترسی متناسب با نقش کاربران است.

> این پروژه نمونه‌ای آموزشی است و با داده‌های ساختگی کار می‌کند؛ به معنی همکاری یا تأیید هیچ دانشگاه واقعی نیست.

## امکانات نسخهٔ اولیه
- مدیریت دانشجویان، استادان و کاربران
- تعریف رشته، درس و نیم‌سال
- انتخاب واحد با کنترل ظرفیت و پیش‌نیاز
- ثبت نمره توسط کاربر مجاز
- مشاهدهٔ کارنامهٔ شخصی دانشجو
- گزارش‌های آموزشی پایه
